# WFP1-527 — Asset file type and size display

**Criterion:** [Asset links] The file format and size should display immediately after the title in all components.

**Pass rule:** `{title} ({EXT}, {size})` with no other text between the title and the metadata, e.g. `Annual report (PDF, 1.2MB)`. **Metadata** in a surtitle, caption, or sibling control is a fail. Missing metadata on an allowed **surface** is a fail.

**metadata** means file format and size: e.g. `PDF, 1.2MB`.

**Surface** is the specific place in a component where the asset link’s title is shown, for example the card title, button label, intro text, or caption.

One component can have several surfaces. A list card banner has three: intro, card, and button. Each is tested on its own.
